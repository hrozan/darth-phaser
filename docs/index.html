DARTH PHASER

Stereo Phase Shifter

Source

A phaser with its notches where you put them.

Two to twelve all-pass stages, a tempo-syncable LFO, stereo offset and damped feedback. VST3 and standalone, for macOS, Windows and Linux.

Every build is produced by GitHub Actions from a tagged commit. Browse every version on the releases page. The builds are unsigned, so the first launch needs the extra step below.

Install

macOS

  1. Unzip, then copy Darth Phaser.vst3 into ~/Library/Audio/Plug-Ins/VST3/
  2. Clear the download quarantine, otherwise Gatekeeper blocks the unsigned build: 
    xattr -dr com.apple.quarantine \
  ~/Library/Audio/Plug-Ins/VST3/"Darth Phaser.vst3"
  3. Rescan plugins in your DAW.

Windows

  1. Unzip, then copy Darth Phaser.vst3 into C:\Program Files\Common Files\VST3\
  2. SmartScreen may warn about an unknown publisher on the standalone. Choose More info, then Run anyway.
  3. Rescan plugins in your DAW.

Linux

  1. Unzip, then copy Darth Phaser.vst3 into ~/.vst3/
  2. Mark the standalone executable if your DAW or desktop needs it: 
    chmod +x Standalone/"Darth Phaser"
  3. Rescan plugins in your DAW.

Build it yourself

CMake fetches JUCE on the first configure, so nothing else needs installing beyond a C++20 compiler.

git clone https://github.com/hrozan/darth-phaser.git
cd darth-phaser
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
